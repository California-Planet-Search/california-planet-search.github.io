CPS members and collaborators who want to use the Jump infrastructure should choose star names according to the following hierarchy:
These rules apply to HIRES and APF and are different from KPF star naming conventions. All starn ames should have no spaces.

1: If "HD" star names are available, use these, but omit the 'HD' prefix. ex. The star Tau Ceti (HD10700) would be "10700".
2: Use Simbad resolveable names including, for example:
   - "TIC123456789", "EPIC9877654321", "KIC1123579", "HIP123456", "KOI-153", "TOI-999"
   - For Gaia DR3 stars, please use this specific convention: "GaiaDR3_2452378776434477184", no truncation and no spaces, including the underscore.
3: Use consistent star names from semester to semester. Observations are linked to programs by exact target name.
4: Historic names are okay if observations are continuing of the same star. ex: K00072, TOI789, T000789.
   - If they are observed for the first time, choose: KOI-72 or TOI-789.
